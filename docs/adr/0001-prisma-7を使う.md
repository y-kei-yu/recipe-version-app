# 0001 Prisma は 7 系の正式版を使う

- 日付：2026-10-04
- 状態：決定

## 状況

Prisma をインストールしようとしたところ、npm の `latest` タグが正式版ではなく `8.0.0-rc`（リリース候補）を指していた。`npm install prisma` や `prisma@latest` では rc が入ってしまう。

## 決定

正式版の最新である `7.10.0` を、バージョンを指定してインストールする。`prisma` と `@prisma/client` は同じバージョンにそろえる。

## 理由・影響

- rc は正式版までに書き方や設定が変わる可能性があり、不具合が残っていることもある
- 学習中は、エラーの原因が自分のコードか Prisma 側かを切り分けにくくなる
- 公式ドキュメントや解説記事の多くは 7 系向けで、調べやすい
- Prisma 8 の正式版が出たら、あらためて上げるかを判断する
